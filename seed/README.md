# Начальная история RUONIA / RGBI

`market_history_seed.csv` — начальная история рыночных показателей
«Отчёта по портфелям» (см. [docs/portfolio_report.md](../docs/portfolio_report.md)).
Едет на рабочий компьютер вместе с проектом. Каждый запуск отчёта дополняет из
него рабочий бэкап `market_history.csv`: только даты и показатели, которых там
ещё нет. Уже записанное он не перебивает.

Выгружено 06.10.2026, период — с 01.01.2025 по 05.10.2026:

| Колонка | Источник | Дата в файле |
|---|---|---|
| `RUONIA` | ЦБ РФ, cbr.ru/hd_base/ruonia — «Ставка RUONIA, % годовых» | дата ставки (публикуется на следующий рабочий день) |
| `RGBI` | Мосбиржа, iss.moex.com — индекс RGBI (режим SNDX), цена закрытия | дата торгов |
| `RWA` | пусто — открытого источника нет, дописывается вручную | — |

Даты — по тому же правилу, что в отчёте: значение стоит под датой, к которой
оно относится (дата позиций T-1). RUONIA начинается с 09.01.2025: в
новогодние праздники ставка не рассчитывалась. RGBI есть и за часть
нерабочих дней, в которые биржа торговала, — там RUONIA пустая.

Файл можно править в Excel: колонки `date` (или `Дата`), `RUONIA`, `RGBI`,
`RWA`. CSV из русского Excel (через «;», с запятой) тоже читается.
