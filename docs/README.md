# Документация по отчётам: что грузим и куда

По файлу на каждый отчёт консоли. В каждом — откуда берутся данные, какой
файл получается на выходе и **что лежит в каждой колонке таблицы в базе BI**.
Как запускать отчёты и настраивать пути — в [README проекта](../README.md).

| Отчёт | Команда | Источник | Выходной файл | Семейство таблицы |
|---|---|---|---|---|
| [ОВП](ovp.md) | `ovp` | Excel ОВП (форма 634) | `<имя>_converted.csv` | своё (ОВП) |
| [Структура баланса](balance_struct.md) | `balance-struct` | `ПФ_дд_мм_гггг.xlsx` | `Навигатор_<имя>.csv` | оси `axis_*` |

## Три семейства выходных таблиц

**1. Длинный формат с осями** (Структура баланса, ЧПД, NIM, Динамика портфелей,
Отчёт по портфелям). Одна строка — одно значение. Что это за значение,
говорят оси:

| Колонка | Смысл |
|---|---|
| `date_` | дата значения, `ГГГГ-ММ-ДД` |
| `axis_0` | отчёт — по нему отчёты различаются в общей таблице |
| `axis_1` … `axis_4` | уровни иерархии / измерения; у каждого отчёта свои (см. его файл) |
| `axis_5` | единица измерения (ЧПД, NIM) |
| `value` | число |
| `text_value` | текст (только «Динамика» и «Отчёт по портфелям») |
| `nversionid` | версия; заполнена только у Структуры баланса |
| `id` | номер строки **внутри файла** — ключом не является |

Набор и порядок колонок у отчётов этого семейства немного различаются (у
Структуры баланса нет `id`, у ЧПД и NIM есть `axis_5`, у портфельных отчётов
есть `text_value`). Если хочется держать их в одной таблице, заведите её по
объединению колонок: `id, date_, axis_0, axis_1, axis_2, axis_3, axis_4,
axis_5, value, text_value, nversionid`, а при загрузке сопоставляйте колонки
**по имени, а не по позиции**.

**2. Ставки** (Трансфертные ставки, Ставки ОФЗ): `date_, name_group, name_st,
[scurrency, stype,] unit, type_val, fvalue`. У ОФЗ нет `scurrency` и `stype`.

**3. ОВП** — своя плоская таблица: `id, ord, category_name, subcategory,
curr_balance, reserve_msfo, currency, report_date`.

## Общие правила для всех файлов

- **Даты** — всегда `ГГГГ-ММ-ДД` (у NIM месяц пишется как первое число:
  `2026-09-01`).
- **Разделитель** — запятая, **кроме ОВП** (`;`).
- **Кодировка** — UTF-8 с BOM (`utf-8-sig`), **кроме ЧПД** (UTF-8 без BOM).
- **Десятичный разделитель** — точка.
- **`id` нигде не ключ.** В каждом файле нумерация начинается заново (с 0
  или с 1), а в объединённом файле (`--combine`) номера повторяются. Ключ
  каждой таблицы указан в описании отчёта.
- **Единицы** и число знаков можно поменять настройкой «Округление» (см.
  README проекта). Где у отчёта есть колонка единицы (`axis_4`/`axis_5`/`unit`),
  она меняется вместе со значением; где колонки единицы нет (ОВП, Структура
  баланса), смена единицы в файле никак не видна — менять её нужно
  согласованно с BI.

## Как читать описание отчёта

В каждом файле одни и те же разделы:

1. **Источник** — какой файл (или API), где он лежит, как называется, какой
   лист и какие колонки/строки из него читаются.
2. **Выходной файл** — имя, разделитель, кодировка, одна дата или много.
3. **Таблица в базе** — колонки, тип, откуда берётся значение.
4. **Ключ и загрузка** — по каким колонкам строка уникальна и как грузить
   повторную выгрузку без дублей.
5. **Особенности** — то, что легко сломать или неправильно понять.
