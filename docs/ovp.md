# ОВП (открытая валютная позиция, форма 634)

Код: [reports/ovp/etl.py](../reports/ovp/etl.py). Команда: `python console.py ovp`.

## Источник

Excel-отчёт ОВП из папки `ovp_dir` (маска `ovp_glob`, по умолчанию `*.xlsx`).
Типового имени с датой у файла нет, поэтому самый свежий определяется по дате
изменения файла.

Если в книге несколько листов, лист нужно выбрать (в консоли — из списка, из
командной строки — `--sheet`). Отчёт понимает два макета листа и определяет
макет сам.

**Новый макет (один лист на все валюты).**
- Дата — первая `ДД.ММ.ГГГГ` в заголовке листа (первые 12 строк).
- В строке заголовков ищутся блоки валют `CNY`, `USD`, `EUR`/`EURO`; под каждым
  — колонки «Валютный Баланс» и «Резервы МСФО». Нужны все три валюты.
  Колонки ИТОГО не читаются.

**Старый макет (лист на валюту).**
- Каждый лист, кроме содержащих «СВОД», — одна валюта; имя листа идёт в
  `currency`.
- Строка дат ищется в первых 20 строках. Под датой — колонка баланса, справа
  от неё — колонка резерва. Берётся **только последняя дата**, если не включена
  полная история для валюты.

**Строки.** Колонка A, маркер «•» отбрасывается. Строка попадает в выгрузку,
только если её название есть в справочнике категорий (см. ниже). Остальные
строки пропускаются молча.

## Выходной файл

`<имя исходного файла>_converted.csv` (или `combined_<дата>_converted.csv` при
`--combine`), **разделитель `;`**, UTF-8 с BOM.

## Таблица в базе

| Колонка | Тип | Что в ней | Откуда |
|---|---|---|---|
| `id` | int | сквозной номер строки в файле, с 1 | счётчик |
| `ord` | int | порядок строки внутри блока «валюта + дата», с 1 | счётчик |
| `category_name` | text | категория верхнего уровня | строка-категория над подкатегорией |
| `subcategory` | text | подкатегория; **пусто у строки самой категории** | название строки |
| `curr_balance` | int | остаток (валютный баланс) | колонка «Валютный Баланс» |
| `reserve_msfo` | int | резерв МСФО | колонка «Резервы МСФО» |
| `currency` | text | `CNY`, `USD`, `EURO` (в новом макете `EUR` пишется как `EURO`); в старом — имя листа | заголовок блока / имя листа |
| `report_date` | date | дата отчёта | заголовок листа (новый) / строка дат (старый) |

## Ключ и загрузка

Ключ: `(report_date, currency, category_name, subcategory)`.
`id` и `ord` ключом не являются. Повторная выгрузка за ту же дату —
перезапись строк этой даты.

## Особенности

- Пустые и нечисловые значения пишутся как **0**, а не пусто. Дробная часть
  **отбрасывается** (`int`), а не округляется.
- Единица — та, что в исходном файле. Колонки единицы в выгрузке нет.
  Настройка «Округление» может делить значения (÷1000 и т.д.); это никак не
  отражается в файле.
- Названия категорий содержат опечатки исходной формы («финасовых») — их нельзя
  «исправлять» в базе, иначе связь с новыми выгрузками потеряется.
