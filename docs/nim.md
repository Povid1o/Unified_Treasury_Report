# NIM (чистая процентная маржа)

Код: [reports/nim/etl.py](../reports/nim/etl.py). Команда: `python console.py nim`.

## Источник

Файл `NIM_гггг_мм.xlsx` из папки `nim_dir` (шаблон — `nim_regex`).

- Лист ищется среди всех листов книги по маркерам в колонке A: `NIM - ОСНОВА`,
  `NIM - RUR`, `NIM - ВАЛЮТА`.
- Читаются колонки A:N. Колонки B:N — **месяцы**. Даты берутся из строки
  самого верхнего найденного маркера, в виде `ГГГГММ` (`202609` →
  `2026-09-01`).
- **Блок ОСНОВА** — четыре строки сразу под маркером, по позиции (подписи у
  них одинаковые, по тексту их не различить):

| Строка под маркером | axis_1 | axis_2 |
|---|---|---|
| +1 | `NIM` | `ALL` |
| +2 | `% результат` | `ALL` |
| +3 | `NIM` | `RUR` |
| +4 | `NIM` | `CUR` |

- **Блоки RUR и ВАЛЮТА** — строки с подписями «% Активы» и «% Пассивы» внутри
  блока, ищутся по тексту:

| Блок | axis_1 | axis_2 |
|---|---|---|
| NIM - RUR | `% Активы`, `% Пассивы` | `RUR` |
| NIM - ВАЛЮТА | `% Активы`, `% Пассивы` | `CUR` |

## Выходной файл

`<имя исходного файла>_converted.csv` (или `combined_<дата>_converted.csv`),
разделитель `,`, UTF-8 с BOM. Порядок колонок: `id, date_, axis_0, axis_1,
axis_2, axis_3, value, axis_4, nversionid, axis_5`.

## Таблица в базе

| Колонка | Тип | Что в ней | Откуда |
|---|---|---|---|
| `id` | int | номер строки в файле, с 1 | счётчик |
| `date_` | date | первое число месяца | заголовок колонки (`ГГГГММ`) |
| `axis_0` | text | всегда `NIM` | константа |
| `axis_1` | text | `NIM`, `% результат`, `% Активы`, `% Пассивы` | см. таблицы выше |
| `axis_2` | text | `ALL`, `RUR`, `CUR` | см. таблицы выше |
| `axis_3` | text | пусто | — |
| `value` | decimal / пусто | значение в **%**, 2 знака | ячейка |
| `axis_4` | text | пусто | — |
| `nversionid` | text | пусто | — |
| `axis_5` | text | пусто | — |

Значения `NIM`, `% Активы`, `% Пассивы` в исходнике — доли; в выгрузке они
умножены на 100 (0.0412 → 4.12). `% результат` уже в процентах в исходнике и
**не** умножается.

## Ключ и загрузка

Ключ: `(date_, axis_1, axis_2)`. Файл NIM за следующий месяц обычно содержит и
прошлые месяцы, поэтому грузить нужно upsert'ом по ключу.

## Особенности

- Пустая или нечисловая ячейка даёт строку с пустым `value`: строка пишется
  всё равно.
- Колонки без даты в заголовке дают строки с пустым `date_`. Такие строки
  стоит отсеивать при загрузке.
- Если маркер блока не найден, блок пропускается с предупреждением в логе: в
  выгрузке просто не будет этих строк.
- Единица в файле не подписана (`axis_5` пустой), значения — проценты.
