# Ставки ОФЗ (кривая доходности, CBonds)

Код: [reports/ofz_rates/etl.py](../reports/ofz_rates/etl.py).
Команда: `python console.py ofz-rates`. Вариант без Python, прямо из Excel, —
[excel_ofz/README.md](../excel_ofz/README.md): на выходе тот же формат.

## Источник

CBonds API, эндпоинт `get_index_value_new`, индексы `RUB_Yield_Curve_<срок>`
для сроков **1Y, 2Y, 3Y, 4Y, 5Y, 6Y, 9Y, 10Y**. Логин и пароль — в
`CBonds_API/.env`.

Период задаётся одним из трёх способов:
- дата + глубина назад (по умолчанию: сегодня и 90 дней назад —
  `ofz_lookback_days`);
- интервал `--date-from` / `--date-to`;
- список дат `--dates`.

Архив CBonds — не глубже 100 календарных дней.

## Выходной файл

Один файл `ofz_report.csv` (настройка `ofz_output_path`), **перезаписывается
каждым запуском**. Разделитель `,`, UTF-8 с BOM. В файле все даты периода.

## Таблица в базе

| Колонка | Тип | Что в ней | Откуда |
|---|---|---|---|
| `date_` | date | дата значения | поле `date` ответа API |
| `name_group` | text | всегда `Доходность ОФЗ` | константа |
| `name_st` | text | срок: `1Y` … `10Y` | индекс |
| `unit` | text | всегда `%` | константа |
| `type_val` | text | всегда `Значение` | константа |
| `fvalue` | decimal | доходность, %, 2 знака | поле `value` ответа API |

## Ключ и загрузка

Ключ: `(date_, name_group, name_st)`. Дубли по ключу удаляются ещё в ETL.
Соседние выгрузки пересекаются по датам (90 дней назад каждый раз), поэтому
**грузить только upsert'ом по ключу**: простая дозапись задвоит историю.

## Особенности

- Пропусков в файле не бывает: ETL проверяет это перед записью и падает с
  ошибкой.
- Показатели «Размещение ОФЗ: Спрос / Разместили» и «Операции: Объём торгов»
  через доступные эндпоинты CBonds получить нельзя, их в выгрузке нет (причины
  — в логе и в `KNOWN_GAPS` в коде).
- Таблицу можно делить с «Трансфертными ставками» — см. их описание.
