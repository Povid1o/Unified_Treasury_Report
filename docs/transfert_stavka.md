# Трансфертные ставки (ЕТС)

Код: [reports/transfert_stavka/etl.py](../reports/transfert_stavka/etl.py).
Команда: `python console.py transfert-stavka`.

## Источник

**Два файла за раз**: короткие ставки (до 3 месяцев) и длинные (свыше 3
месяцев). Папки — `transfert_short_dir` и `transfert_long_dir`.

**Короткие:** в имени файла дата вида `с ДД.ММ.ГГГГ` (`transfert_short_regex`).
Листы `RUR`, `USD`, `EUR`, `CNY`, заголовок во 2-й строке. Срок — по колонке
«до, дней»:

| «до, дней» | `name_st` |
|---|---|
| 1 | `ON` |
| 31 | `1M` |
| 90 | `3M` |

Колонка значения по листам:
- RUR — «Трансфертная кривая размещения (КРЕДИТЫ), рубли»;
- USD — «Трансфертная кривая размещения, USD»;
- EUR — «Трансфертная кривая размещения, евро»;
- CNY — «Трансфертная кривая размещения, CNY».

Значения 99, 0 и «-» отбрасываются.

**Длинные:** в имени файла дата вида `с ДД ММ ГГГГ` (`transfert_long_regex`).
Листы те же, заголовок в 1-й строке. Срок — по колонке «Месяц»:

| «Месяц» | `name_st` | запасной вариант по «от, дней» |
|---|---|---|
| 12 | `1Y` | 366 |
| 24 | `2Y` | 732 |
| 36 | `3Y` | 1098 |
| 60 | `5Y` | 1830 |
| 84 | `7Y` | 2562 |
| 120 | `10Y` | 3660 |
| 150 | `15Y` | — |

Если «Месяц» не заполнен, срок определяется по «от, дней». При совпадении
главнее значение по «Месяцу». Колонка значения: у RUR — «Трансфертная кривая
размещения (месяц), рубли», у остальных — 4-я колонка листа. Значение 99
отбрасывается.

## Выходной файл

`result_transert_<сегодня>.csv`, разделитель `,`, UTF-8 с BOM.

## Таблица в базе

| Колонка | Тип | Что в ней | Откуда |
|---|---|---|---|
| `date_` | date | дата ставки | имя файла (у коротких и длинных — каждая из своего) |
| `name_group` | text | всегда `ЕТС` | константа |
| `name_st` | text | срок: `ON`, `1M`, `3M`, `1Y` … `15Y` | см. таблицы выше |
| `scurrency` | text | `RUB`, `USD`, `EUR`, `CNY` | лист (`RUR` → `RUB`) |
| `stype` | text | всегда `FIX` | константа |
| `unit` | text | всегда `%` | константа |
| `type_val` | text | всегда `Значение` | константа |
| `fvalue` | decimal | ставка, % — как в исходнике, без округления | колонка значения |

## Ключ и загрузка

Ключ: `(date_, name_group, name_st, scurrency, stype)`. Повторная выгрузка за
ту же дату — upsert по ключу.

## Особенности

- Даты коротких и длинных ставок берутся из имён своих файлов и могут
  различаться, если файлы за разные дни.
- Таблицу можно делить со «Ставками ОФЗ»: у них те же колонки, кроме
  `scurrency` и `stype` (у ОФЗ их нет — в общей таблице оставьте пустыми).
