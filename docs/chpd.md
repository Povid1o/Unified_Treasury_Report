# ЧПД (чистая процентная позиция / структура баланса для ЧПД)

Код: [reports/chpd/etl.py](../reports/chpd/etl.py). Команда: `python console.py chpd`.

## Источник

Файл `ЧПД гггг мм дд.xlsx` из папки `chpd_dir` (шаблон — `chpd_regex`).

- Лист **`Table`**, колонки A:M, строки 2–33.
- Колонка A — название статьи. Колонки B:M — шесть пар «объём, доля»:

| Колонки | Что | Грузится? |
|---|---|---|
| B, C | дата 1, RUB: объём, % | нет |
| D, E | дата 2, RUB: объём, % | нет |
| F, G | изменение за неделю, RUB | нет |
| **H, I** | **дата 1, ИТОГО: объём, %** | **да** |
| **J, K** | **дата 2, ИТОГО: объём, %** | **да** |
| L, M | изменение за неделю, ИТОГО | нет |

- Дата берётся из объединённой ячейки заголовка над парой колонок.
- Статья определяется по названию (а не по номеру строки) по справочнику ниже.
  Одинаковые названия в Активах и Пассивах («Юридические лица», «SWAP»)
  различаются по контексту. Строки, которых нет в справочнике, отбрасываются с
  предупреждением.

## Выходной файл

`<имя исходного файла>_converted.csv` (или `combined_<дата>_converted.csv`),
разделитель `,`, **UTF-8 без BOM**. Две даты в одном файле.

## Таблица в базе

| Колонка | Тип | Что в ней | Откуда |
|---|---|---|---|
| `id` | int | номер строки в файле, с 0 | счётчик |
| `date_` | date | дата 1 или дата 2 | заголовок пары H/I или J/K |
| `axis_0` | text | всегда `ЧПД` | константа |
| `axis_1` | text | `Активы` / `Пассивы` | справочник |
| `axis_2` | text | статья 2-го уровня или пусто | справочник |
| `axis_3` | text | статья 3-го уровня или пусто | справочник |
| `axis_4` | text | статья 4-го уровня или пусто | справочник |
| `value` | int / пусто | объём (**млрд руб**, до целых) или доля (**%**, до целых) | колонки H/J или I/K |
| `nversionid` | text | пусто | — |
| `axis_5` | text | единица: `млрд руб` у объёма, `%` у доли | константа |

На каждую статью и дату приходится **две строки**: объём (`axis_5 = млрд руб`)
и доля (`axis_5 = %`). Строка объёма пишется всегда, даже с пустым значением.
Строка доли пишется, только если доля заполнена. Доля в файле — ×100 от
исходной (0.153 → 15).

## Ключ и загрузка

Ключ: `(date_, axis_1, axis_2, axis_3, axis_4, axis_5)`. Дата 1 текущего
файла обычно равна дате 2 предыдущего, поэтому одна и та же дата приходит
дважды. Грузить нужно upsert'ом по ключу.

## Особенности

- «-» в ячейке пишется как 0.
- Единицу объёма можно поменять настройкой «Округление». Подпись в `axis_5`
  меняется вместе со значением.
- Файл без BOM: при загрузке явно указывайте кодировку UTF-8.
