# Unified_Treasury_Report

Единая консоль ETL-отчётов казначейства для BI.

## Установка

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Учётные данные CBonds лежат в `CBonds_API/.env` (`CBONDS_LOGIN`, `CBONDS_PASSWORD`).

Пути к папкам с исходными Excel-файлами и результатами для файловых отчётов
(BalanceStruct, ЧПД, NIM, Трансфертные ставки) настраиваются в [config.py](config.py).

## Запуск

```bash
python console.py                              # интерактивное меню: выбрать отчёт -> параметры -> запуск
```

Без аргументов запускается интерактивное меню: выбор отчёта из красиво
оформленной таблицы, ввод параметров, спиннер во время загрузки с живыми
логами поверх него. Ctrl+C в любой момент (на выборе отчёта, при вводе
параметров, во время самой загрузки) отменяет только текущую операцию и
возвращает в меню — программа не закрывается.

Каждый отчёт можно запустить и напрямую аргументами командной строки.

### Ставки ОФЗ (CBonds API)

Три взаимоисключающих режима периода:

```bash
python console.py ofz-rates --date 2026-07-01 --lookback-days 30    # одна дата + история назад (по умолчанию)
python console.py ofz-rates --date-from 2026-06-01 --date-to 2026-06-10   # интервал дат
python console.py ofz-rates --dates 2026-06-01,2026-06-15,2026-07-01      # список конкретных (не обязательно смежных) дат
```

### Файловые отчёты (ОВП, Структура баланса, ЧПД, NIM)

```bash
python console.py balance-struct --date 2026-06-18            # один файл на дату
python console.py balance-struct --dates 2026-06-18,2026-06-25 --combine   # несколько файлов -> ОДИН csv
python console.py chpd --inputs "a.xlsx" "b.xlsx"              # несколько файлов -> отдельные csv (по умолчанию)
python console.py ovp --inputs report1.xlsx report2.xlsx --combine
python console.py transfert-stavka --short-date 2026-03-17 --long-date 2026-04-30
```

Без `--date`/`--input`/`--inputs`/`--dates` файловые отчёты сами находят
самый свежий файл в папке источника (см. `config.py`).

В интерактивном режиме консоль показывает 5-10 последних найденных файлов
(чтобы не засорять экран более старыми) и позволяет выбрать сразу несколько:
номерами из списка, датами (YYYY-MM-DD, в том числе за пределами показанных
5-10) или именами файлов через запятую — можно смешивать. По умолчанию
каждый выбранный файл сохраняется в свой CSV; если выбрано больше одного
файла, консоль спросит, объединить ли всё в один CSV.

У ОВП нет типового имени файла с датой (в отличие от остальных), поэтому его
`SourceConfig` в `config.py` сортирует файлы по дате изменения (mtime), а не
по дате из имени — во всём остальном (топ-N, мультивыбор, batch) работает
так же, как у остальных отчётов.

Если папка из `config.py` недоступна (не примонтирован сетевой диск,
опечатка в пути) или в ней не нашлось ни одного подходящего файла —
консоль не падает с ошибкой, а предлагает вписать путь(и) к файлу вручную.

«Трансфертные ставки» — особый случай: отчёту нужны ДВА файла за раз
(короткие + длинные ставки), поэтому пакетный режим (несколько запусков за
один вызов) для него пока не реализован.

## Структура проекта

- `CBonds_API/` — перенесённая библиотека-клиент CBonds JSON API (общая для всех отчётов).
- `common/` — общие утилиты, переиспользуемые разными отчётами:
  - `ui.py` — оформление консоли (rich): меню, спиннер, стилизованные сообщения.
  - `logging_utils.py` — единое логирование (RichHandler в консоль + `logs/<report>.log`).
  - `file_discovery.py` — поиск входных файлов по дате, зашитой в имени файла (топ-N дат / список дат / имя файла, одиночный и множественный выбор).
  - `batch.py` — запуск ETL по списку файлов: раздельные CSV (по умолчанию) или один объединённый (`--combine`).
- `config.py` — пути к папкам с исходными данными и результатами для файловых отчётов (`SourceConfig` на каждый источник).
- `reports/<report_slug>/` — код конкретного отчёта: `etl.py` (получение и преобразование данных) + `report.py` (обёртка для консоли: CLI-аргументы и интерактивный режим).
  - `reports/ofz_rates/` — «Ставки ОФЗ» (кривая доходности ОФЗ из CBonds API).
  - `reports/ovp/` — «ОВП» (конвертация Excel-отчёта «Открытая валютная позиция» в CSV).
  - `reports/balance_struct/` — «Структура баланса» (разбор Excel «ПФ_ДД_ММ_ГГГГ» по иерархии активов/пассивов).
  - `reports/chpd/` — «ЧПД» (разбор Excel «ЧПД YYYY MM DD», лист Table).
  - `reports/nim/` — «NIM» (разбор Excel «NIM_YYYY_MM» по текстовым маркерам).
  - `reports/transfert_stavka/` — «Трансфертные ставки» (два файла: короткие + длинные сроки).
- `console.py` — точка входа: реестр отчётов + меню/CLI.
- `output/<report_slug>/` — результаты запусков (для файловых отчётов путь берётся из `config.py`).
- `logs/` — логи запусков (по одному файлу на отчёт).

## Добавление нового отчёта

1. Создать `reports/<slug>/etl.py` с получением и преобразованием данных.
2. Если у отчёта есть входные файлы с датой в имени — добавить `SourceConfig` в `config.py` и использовать `common.file_discovery` для поиска файла.
3. Создать `reports/<slug>/report.py` с классом, реализующим `reports.base.Report`.
4. Зарегистрировать отчёт в списке `REPORTS` в `console.py`.
